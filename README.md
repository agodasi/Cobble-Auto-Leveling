# AutoCobble

MinecraftのCobblemon（コブルモン）Mod用自動化補助Modです。
周囲のポケモンを検知し、自動的に近づいて戦闘を開始し、最適な技選択や捕獲までをサポートします。

## 主な機能

- **自動追跡**: 周囲30ブロック以内の最も近い野生のポケモンを検知し、自動的に接近します。
- **自動戦闘開始**: ポケモンに到達すると、自動的に手持ちのポケモンを繰り出し（またはインタラクトし）、戦闘を開始します。
- **インテリジェント戦闘AI**:
  - 相性を考慮した最適な技の自動選択。
  - HPが低下した際や強制交代時の自動スイッチ。
- **自動捕獲**:
  - 色違い（Shiny）、伝説（Legendary）、幻（Mythical）、ウルトラビースト（Ultra Beast）を自動判別。
  - 相手のHPを安全に削り（みねうち等の技を優先）、HPが低下するとホットバーにあるボールを自動で投げます。
- **スムーズな移動**: 障害物がある場合の自動ジャンプや、距離に応じたスプリントに対応。

## 操作方法

- **Pキー** (デフォルト): 自動化機能の ON/OFF 切り替え。

## 前提Mod / 動作環境

このModは以下の環境で動作を確認しています。

- **Minecraft**: `1.20.1`
- **Forge**: `47.3.33` 以上
- **Kotlin for Forge**: `4.10.0`
- **Cobblemon**: `1.5.2` (Minecraft 1.20.1用)

### 推奨Mod
- **Baritone**: `1.10.3` (API) - 導入されている場合、移動制御の補助に使用されます。
